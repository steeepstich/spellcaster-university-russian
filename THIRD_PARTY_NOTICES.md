# Сторонние компоненты

Установщик собирается с использованием следующих проектов:

- [Python](https://www.python.org/) — Python Software Foundation License.
- [UnityPy](https://github.com/K0lb3/UnityPy) — MIT License.
- [PyInstaller](https://pyinstaller.org/) — GPL 2.0 с исключением для распространения собранных приложений.

Собранный установщик может включать транзитивные зависимости UnityPy и PyInstaller. Их лицензии сохраняются в соответствии с условиями соответствующих проектов.
