# Русификатор Spellcaster University

Неофициальный полный русский перевод **Spellcaster University** для Windows.

Переведено 5208 строк: меню, обучение, карты, комнаты, события, задания, описания, интерфейс и игровой журнал. Перевод машинный с ручными исправлениями терминологии и служебной разметки.

## Установка

1. [Скачайте `SpellcasterUniversity_RU_Installer.exe`](release/SpellcasterUniversity_RU_Installer.exe).
2. Полностью закройте игру.
3. Запустите установщик и выберите `1 — установить русификацию`.
4. Если игра не найдена автоматически, укажите папку, где находится `Spellcaster University.exe`.
5. Запустите игру. Выбирать язык в настройках не требуется.

Установщик создаёт резервную копию:

```text
<папка игры>\_Russian_Backup\resources.assets.original
```

## Удаление

Снова запустите установщик и выберите `2 — восстановить оригинал`.

Также можно проверить целостность файлов игры в Steam.

## Совместимость

Русификатор проверяет SHA-256 оригинального файла и не изменяет неизвестные версии игры. Поддерживается версия, в которой оригинальный `resources.assets` имеет SHA-256:

```text
DDE8696DE7B61800F52C1137F2BDDE5DFE01D6F7E90457AB2CE78F663D357549
```

Если Steam обновит игру, создайте issue и приложите номер версии — потребуется обновлённая сборка русификатора.

## Безопасность и права

- Репозиторий не содержит оригинальных файлов игры.
- В языковой схеме сохранены только технические идентификаторы; оригинальные тексты игры не публикуются.
- Установщик применяет перевод только к локально установленной совместимой копии.
- Spellcaster University и все игровые материалы принадлежат их правообладателям.
- Это неофициальный фанатский проект, не связанный с Sneaky Yak Studio или издателем.

## Сборка из исходников

Требуется Python 3.12 x64.

```powershell
python -m pip install -r requirements-build.txt
.\build.ps1
```

Файл `dist\SpellcasterUniversity_RU_Installer.exe` можно проверить командой, подставив свой путь к папке игры:

```powershell
.\dist\SpellcasterUniversity_RU_Installer.exe --install --game "ПУТЬ_К_ПАПКЕ_ИГРЫ"
```

Контрольная сумма опубликованного установщика находится в `SHA256SUMS.txt`.
